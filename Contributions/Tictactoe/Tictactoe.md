# Tic-Tac-Toe example application

This project is a SmallJS implementation of Tic-Tac-Toe,\
a human player against a computer opponent, \
in a browser client app with DOM interaction.

This app was created by Claude as a conversion form the example app Counter.\
The file [Tutorial.md](Tutorial.md) contains a link to the video of the creation plus an outline.

## Running

First run `./startWebServer.sh`.
Then start the project in VSCode with `F5`.
